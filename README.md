# Abigail Ramarukuru — Hacker Terminal Portfolio

A responsive personal portfolio website built using HTML, CSS, and vanilla JavaScript.

## Run locally
Open `index.html` in a browser. No installation or build tools are needed.

## Deploy to GitHub Pages
1. Create a public GitHub repository named `portfolio-website`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. In repository **Settings → Pages**, select **Deploy from a branch**, **main**, and **/(root)**, then save.
4. Visit `https://abigailramarukuru-a11y.github.io/portfolio-website/` after GitHub Pages finishes publishing.
